# 台股強勢股掃描

每日盤後自動掃描全市場(上市+上櫃普通股),產生兩份清單:

- **SEPA Trend Template** — Minervini 七條件 + RS Rating(相對大盤超額報酬,全市場百分位 1–99)
- **當日強勢** — 漲幅 ≥ 4%、量比 ≥ 1.5、成交值 ≥ 1 億

同時每日重建台指選擇權(TXO)的 **GEX 位階**(Call Wall / Put Wall / 山頂 / 山谷 / Micro Flip / Macro Zero),座標為期貨遠期價。

> ⚠️ **先讀這個**:GEX 位階經過 278 個交易日的實測,**對交易決策幫助有限** —— 牆的彈回率與隨機位階無異、flip 當觸發點沒有方向性、唯一顯著的波動訊號已被隱含波動率定價完。詳見〈[實測結果](#-實測結果這些位階對交易決策幫助有限)〉。有價值的是「gamma/OI 集中在哪裡」這個事實陳述本身。

架構:GitHub Actions 每個交易日 15:30(台北)自動抓資料、計算、commit 結果 → GitHub Pages 提供靜態前端。零伺服器、零費用。

## 部署步驟

1. 把這個資料夾推上 GitHub(public 或 private repo 皆可,Pages 需 public 或付費方案)
2. **回補歷史資料**(只需做一次):
   - 本機執行:
     ```bash
     pip install pandas requests numpy scipy
     python scripts/update_data.py --backfill
     python scripts/txo_gex.py --backfill
     ```
   - 個股/大盤呼叫證交所、櫃買中心免費歷史 API,約 280 個交易日跑數分鐘;GEX 呼叫期交所選擇權下載,按月切片,通常一兩分鐘內完成。皆無需金鑰、無需註冊
   - commit 產生的 `data/history.csv.gz`、`data/gex_history.csv`、`docs/data/latest.json`、`docs/data/gex_latest.json` 並 push
3. Repo → Settings → Pages → Source 選 `Deploy from a branch`,分支 `main`、目錄 `/docs`
4. Repo → Settings → Actions → General → Workflow permissions 選 **Read and write**
5. 完成。之後每個交易日 15:30 會自動更新,也可到 Actions 頁面手動觸發

## 篩選邏輯

**SEPA(七條件全過 + RS ≥ 70):**
1. 收盤 > 150MA 且 > 200MA
2. 150MA > 200MA
3. 200MA 上升(對比一個月前)
4. 50MA > 150MA > 200MA
5. 收盤 > 50MA
6. 收盤高於 52 週低點至少 30%
7. 收盤距 52 週高點 25% 以內

RS Rating 採 IBD 式加權:40% 三個月 + 各 20% 六/九/十二個月的**超額報酬**(個股報酬 − 加權股價指數同期報酬),全市場排百分位。上市、上櫃股票統一以加權指數(大盤)為基準,而非各自比較所屬市場的指數。

**當日強勢:** 漲幅 ≥ 4%、量比(當日量/20 日均量)≥ 1.5、成交值 ≥ 1 億。

**動能篩選 + 市場廣度:**

1. 收盤 > 200MA
2. 10MA > 20MA
3. 總市值 ≥ 20 億
4. 成交值 ≥ 5,000 萬
5. 近 21 個交易日績效 ≥ 20%

每日通過的**檔數**就是市場廣度 —— 同樣是大盤上漲,通過的檔數在擴張還是萎縮,代表漲勢是全面的還是集中在少數股。實測這個數字波動極大:2026-05 底 275 檔、06 底 126 檔、07 底剩 **26 檔**、08 底回到 80 檔上下。

**美股版**(`scripts/us_breadth.py`)用同一組條件,門檻改為市值 ≥ $5 億、成交值 ≥ $500 萬,宇宙約 3,300 檔:

- 宇宙與市值:**Nasdaq screener**,一次回傳全美約 7,000 檔
- 每日 K 線:**Yahoo chart API**,逐檔但一次給一整年 —— 所以回補與每日更新成本相同(實測 3,346 檔約 80 秒),不必像台股那樣累積價格檔案

⚠️ Yahoo 那支是**非官方 API**,沒有服務保證,隨時可能改格式或擋人,性質與證交所官方資料完全不同。腳本會統計抓取失敗率,超過 25% 會警告。目前實測缺漏約 4%。歷史廣度受限於 Yahoo 一次只給一年,扣掉 SMA200 的回看後約可回補 50 天。

總市值需要發行股數,上市取證交所公司基本資料 OpenAPI(`t187ap03_L`),上櫃直接在每日行情的「發行股數」欄位裡就有。**兩個來源都只給當下股數、沒有歷史**,所以回補歷史廣度等於用今天的股數乘過去的股價,遇到增減資的個股會失真;市值門檻只是粗篩,影響有限但要知道。SMA200 需要 200 天歷史,所以 280 天的視窗只能回補最近約 80 天的廣度,之後會隨資料累積變長。

兩份清單都要求成交值 ≥ 1 億。少了這道濾網,SEPA 會有三成是一天只成交幾十萬元的個股 —— 技術面條件再漂亮也建不了倉。

門檻都是 `scripts/update_data.py` 頂端的具名常數(`MIN_VALUE`、`MIN_RS`、`DAILY_CHG`、`DAILY_VOL_RATIO`),可自行調整。

## GEX 位階

用 TXO(台指選擇權)每日結算價,透過買賣權平價反推期貨遠期價(基差自動內含,不必另抓加權指數估股利率),Black-76 反推 IV 後計算全鏈 dollar gamma,標出六個關鍵價位:

- **Call Wall / Put Wall** — 現價上/下方 net gamma 最大的履約價
- **山頂 Peak** — gross gamma 最大的履約價
- **山谷 Valley** — 現價下方兩個量能區之間的凹陷(跌破後容易加速的真空帶)
- **Micro Flip** — 總 GEX 由負轉正/正轉負的價位(全部到期日)
- **Macro Zero** — 同上,但只用到期日 > 7 天的合約

山谷是找**局部**低點,不是區間最小值 —— gross gamma 隨著遠離價平單調衰減,取全域最小會永遠落在掃描窗最外緣那根空履約價上。實作先把履約價分箱(近月有 50 點檔,量能遠小於百點檔,不分箱會每根都被誤判成谷),再用 prominence 篩深度。找不到夠深的谷就回空值,不硬給數字;指數水位越低、掃描窗內格數越少,越容易出現空值(實測空值率與指數水位相關 -0.88)。

`regime` 為正代表造市商避險行為傾向壓抑價格波動,為負則傾向放大波動。多空 gamma 幾乎抵銷時會標 **neutral** —— 判斷依據是 `net_ratio`(淨 gamma / 總 gamma),低於 `NEUTRAL_RATIO` 就不給正負。這個門檻有實測依據:`net_ratio` ≤ 0.05 的日子,正負號隔日翻面率是 63~65%(比擲銅板還糟),跨過 0.05 掉到 36%,超過 0.2 只剩 12.5%。

結算日當天到期的合約整批排除:期交所對最後交易日的到期序列不發結算價(整批寫 0),反推不出 IV,且收盤後那份 gamma 不再產生盤中避險。

**盤前快照**:排程跑在台北早上 07:00,此時當日夜盤(前日 15:00~當日 05:00)已收、日盤尚未開,期交所已發布夜盤收盤價但還沒有當日 OI。這時會用夜盤價重算 `gex_now` / `net_ratio` / `regime`,輸出成 `preopen_*` 欄位,前端改以夜盤價為錨點 —— 也就是「以上個交易日的 OI 結構來看,現在這個價格落在正負 Gamma 的哪一側」。位階本身不重算:它們是 OI 結構的性質,而 OI 一天只結算一次。盤前欄位不寫進歷史檔,因為那是尚未收盤那天的暫時狀態。

前端以**價格階梯**呈現:所有位階由高到低排列,台指期實際結算價插在它該在的位置,右欄是距離點數,一眼看得出現在離哪道牆多遠、在翻轉點的哪一側。台指期價格取自期交所 `futDataDown`(商品代碼 `TX`),選 **OI 最大**的月份而非最近月 —— 轉倉在到期前數日就發生,挑近月會抓到正在失去流動性的那一口。選擇權隱含遠期價(`F`)與期貨結算價差一個基差(兩者到期日不同),差距 ≥ 20 點時會另外標一列。

品質過濾門檻(`MIN_OI`、`MIN_PRICE`、`VALLEY_MIN_DEPTH`、`NEUTRAL_RATIO`)會顯著影響結果,都在 `scripts/txo_gex.py` 頂端可調整。

### 📉 實測結果:這些位階對交易決策幫助有限

`scripts/validate_gex.py` 可重跑以下驗證。以下是 **278 個交易日**(2025-07-03 ~ 2026-08-21)跑出來的結果。所有對照組都是**把同一組位階隨機平移**後重算(保留寬度與不對稱比例),不是憑空比較。

| 測試 | 結果 | 判定 |
|---|---|---|
| **牆能當支撐壓力嗎**(碰到後退回牆內) | 實際 34.4% vs 隨機位階 34.1%,第 54 百分位 | ❌ 與隨機無異 |
| 觸及上牆後的穿透深度 | 中位數 **33% 牆距**、90 分位 **90%** | ❌ 真障礙不會這麼容易被穿過 |
| 隔日收盤落在牆內 | 63.7% vs 隨機 60.8%,第 93 百分位 | 🟡 弱,未達顯著 |
| **跌破 Micro Flip 會加速嗎** | 跌破組 0.85% vs 維持組 0.89%,p=0.202 | ❌ 不但沒加速,數字還略低 |
| **跌破後的方向** | 反彈 51% / 續跌 49%,p=1.000 | ❌ 完全隨機 |
| 負 gamma 是否預示大波動 | 隔日 \|報酬\| 中位 1.67% vs 0.88%,控制波動延續後三層中兩層顯著 | ✅ 統計上成立 |
| **↑ 但這個訊號有經濟價值嗎** | 見下方 | ❌ **沒有** |

**決定性測試 —— 訊號早就被 IV 定價了:**

| regime | 天數 | 當日 ATM IV 中位 | 實現/隱含比 |
|---|---|---|---|
| positive | 185 | 22.3% | 0.80 |
| negative | 45 | **38.1%** | 1.01 |

負 gamma 日的隱含波動率是正 gamma 日的 **1.7 倍**(p < 0.0001) —— 選擇權市場早就知道那些日子會震。扣掉 IV 已定價的部分後,GEX 對「實現減隱含」**沒有預測力**(p = 0.084;連續版本 Spearman rho = −0.058, p = 0.330)。

也就是說:「負 gamma → 隔日波動 2 倍」是**真的,但沒有用** —— 那些日子本來就是波動大的日子,而你付的權利金裡已經含了那份波動。

**所以這套東西實際能用的是什麼:**

- ✅ **gamma / OI 集中在哪裡** —— 這是事實陳述,不需要驗證,也不依賴任何行為假設(山頂、山谷、剖面)
- ⚠️ 想知道「今天預期會不會震」,**直接看 ATM IV 就好**,不必繞一圈算 GEX
- ❌ 把牆當支撐壓力、把 flip 當觸發點 —— 資料完全不支持

**保留:** 樣本全部落在同一個大多頭(期間指數 +99%),空頭環境下結論未必相同;腳本共跑約十個檢定,**沒有做多重比較校正**,出現一兩個 p<0.05 屬預期內。判讀請以效果量與對照組分布為主,不要只看 p 值。

### ⚠ 靜態假設在台股不成立 — 哪些數字能信

GEX 的符號採靜態假設:**造市商 long call / short put**(`net = oi_c - oi_p`)。這個假設借自美股 SPX 的慣例 —— 散戶買 put 避險,造市商被迫 short put,於是形成負 gamma。

**用期交所的三大法人留倉實測(免費資料,`callsAndPutsDateDown`),2026-06-24 ~ 08-24 共 43 個交易日:**

| | 符合天數 | 平均淨額 | 與假設 |
|---|---|---|---|
| 自營商 CALL 淨買方 | 39/43(91%) | +4,201 口 | ✅ 相符 |
| 自營商 PUT **淨買方** | 41/43(95%) | +5,217 口 | ❌ **相反** |
| 兩者同時成立 | **2/43(5%)** | | |

原因是市場結構相反:台灣散戶大量**賣 put 收租**(2026-08-24 散戶端 put 空方 59% > 多方 54.5%),自營商接到的是 long put,不是 short put。

**所以哪些能信:**

| 輸出 | 依賴符號假設 | 狀態 |
|---|---|---|
| 山頂 Peak、山谷 Valley | ❌ 用 gross(`oi_c + oi_p`),不涉及誰長誰短 | ✅ 有效 |
| gamma×OI 剖面、`F`、基差 | ❌ | ✅ 有效 |
| Call Wall / Put Wall | ⚠️ 部分(現價上方 put OI 本來就少,下方 call OI 也少) | 🟡 大致可用,實測 8 天中 5-7 天與單邊定義同解 |
| Micro Flip、Macro Zero | ✅ 零軸穿越完全靠符號 | ❌ 不可信 |
| `regime` 正/負 Gamma 判定 | ✅ | ❌ 不可信 |

**不能只是把 put 的符號翻過來** —— 那會讓 `net` 等於 `gross`、永遠是正的,Micro Flip 直接不存在。真正的問題是我們對每個履約價套用同一個符號,但實際的長短分布因履約價而異。要修好需要**逐履約價的流量歸屬**(判斷每筆成交打在買價還賣價),那需要 tick 資料。

還有一層:期交所只分自營商/投信/外資三類,**沒有獨立的「造市者」欄位**。自營商混著登記造市者與方向性自營交易,且只持有全市場約 1/3 部位 —— 連「造市商是誰」在公開資料裡都不乾淨。
